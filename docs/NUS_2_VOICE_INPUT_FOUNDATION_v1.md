# NUS 2.0 Voice Input Foundation v1

Speech recognition is isolated behind `NusVoiceInput`; the reminder and Quick Add systems remain the source of truth. The first production implementation will use `speech_to_text` stable 7.4.0 after platform compatibility review. It is designed for short intermittent commands, which matches NUS quick capture rather than continuous dictation. See pub.dev package documentation for current support and permissions.
