The next implementation slice turns NUS Today from a read-only dashboard into an action surface.

- Quick Add creates real local reminders through the existing ScheduleStore and notification pipeline.
- NUS Copilot opens the existing AI Hub.
- No database migration is required.
- Existing authentication, finance, shopping, medication, appointment, and notification flows remain intact.
